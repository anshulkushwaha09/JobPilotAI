# 🚀 JobPilot AI

> AI-powered Job Search Assistant built with ASP.NET Core 8, Angular 19 and SQL Server.

---

## 📌 Overview

JobPilot AI helps software professionals find jobs from multiple sources, rank them using AI, track applications and prepare for interviews—all from a single dashboard.

---

## ✨ Features

- User Registration & Login
- Google Authentication
- AI Job Matching
- Job Aggregation
- One-Click Apply
- Application Tracker
- AI Interview Assistant
- Admin Dashboard

---

## 🛠 Tech Stack

### Backend
- ASP.NET Core 8 Web API
- Dapper
- SQL Server
- JWT Authentication

### Frontend
- Angular 19
- Bootstrap 5
- Angular Material

### AI
- Google Gemini API

### Deployment
- Render
- Netlify
